## 📌 About The Project

TexoR is a modern frontend developer portfolio website built to showcase my skills, projects, and experience in web development.

The project focuses on creating a clean, responsive, and visually engaging user experience with a modern dark interface and a purple programming-inspired visual style.

TexoR is designed as a multi-page portfolio and includes dedicated pages for the home section, about information, technical skills, projects, and contact information.
